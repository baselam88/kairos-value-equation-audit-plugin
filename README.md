# Value Equation Audit

Audits any offer through the four value variables (dream outcome x likelihood / time delay x effort) and improves the variables instead of cutting price.

A free plugin from KAIROS AI Systems — one focused tool that does one job well for a
small business: no suite to learn, no setup project, no account required beyond your
agent host.

## What it does

Score the offer on each variable from the owner's own facts, name the weakest variable, output three concrete changes that raise value. A price cut is a failed audit — never the output.

## How to use it

Add this plugin to a compatible agent host (Cursor, Grok Bot, or another
agent-plugins host), then ask in plain language, for example:

> Use the Value Equation Audit to help me: audits any offer through the four value variables (dream outcome x likelihood / time delay x effort) and improves the variables instead of cutting price — I'll paste the details.

The plugin works from the facts you give it — your services, your prices, your
records. It never invents a number, a policy, or a result; anything it projects is
labelled an estimate with its basis. Drafts that would go to a customer stay drafts
until you approve them.
